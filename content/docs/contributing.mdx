Welcome. Trajectory IR is Apache-2.0 open source.

## Checklist

1. Read the engine [CONTRIBUTING.md](https://github.com/Coder-s-OG-s/Trajectory-IR/blob/main/CONTRIBUTING.md)
2. Sign off commits (DCO): `git commit -s`
3. Prefer **Go** for new Phase 1B/1C features; keep Python as parity
4. Do **not** reimplement durable execution — plug into Temporal / DBOS / Restate
5. Spec questions → [GitHub issue](https://github.com/Coder-s-OG-s/Trajectory-IR/issues) on the engine
6. **Website-only** docs/UX PRs belong in [Trajectory_IR-website](https://github.com/Coder-s-OG-s/Trajectory_IR-website); runtime changes go to [Trajectory-IR](https://github.com/Coder-s-OG-s/Trajectory-IR)

## Suggested first paths

| You want to… | Start |
