## Goal

Interrupt a non-idempotent deploy-style tool and see resume use the sealed plan instead of inventing a new one — without blindly double-firing the write.

## Command

```bash
cd Trajectory-IR/go
go run ./examples/kill_mid_deploy -workdir ./demo-data
```

## What to observe

- Decision sealed before the dangerous tool
- Crash / kill mid-flight
- Resume path honors block-and-gate semantics for non-idempotent work
