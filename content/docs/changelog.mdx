Site summary of the engine [CHANGELOG](https://github.com/Coder-s-OG-s/Trajectory-IR/blob/main/CHANGELOG.md). Prefer the engine file for the full history.

## [Unreleased]

### Changed

- Sandbox rejects `AGENT_SPAWN` and `SENSITIVE` in addition to `NON_IDEMPOTENT_WRITE`; error string standardized to `SANDBOX_FORBIDDEN`.

## [0.2.2] - 2026-09-07

### Added

- In-tree MCP server (`trajir-mcp`) with status / export / import / verify-signature tools
- Conformance **R09–R11** for `trajir-pkg-sig-v1` (Go + Python sign/verify, cross-language)
- Phase CI harden: OpenSSF Scorecard, CodeQL, gitleaks, actionlint, SBOM on release
- CNCF Sandbox process pack (`MAINTAINERS`, `GOVERNANCE`, `ADOPTERS`, scope docs)

### Changed

- Package signatures documented as **shipped**; Sigstore remains future
- SECURITY supported versions aligned to **0.2.x**

## [0.2.1] - 2026-08-13

Phase 1C harden-and-adopt patch: live Docker matrix (Postgres + MinIO + Temporal), merge policy / branch protection on `main`, release workflow proof.

## [0.2.0] - 2026-08-11

Phase 1B: **Go is the primary SDK**. Python remains the reference / parity port. Go drivers, adoption host demo, deeper CI, client honesty fixes.

## [0.1.x] - 2026-08

Phase 1A library surface: dual-language IR, portable `.tir`, storage drivers, Restate hooks, sandbox (R06), conformance R01–R08, Temporal as Go production durable backend.

## [v0.1.0-draft] - 2026-07-27

Initial spec, governance, and infrastructure drafts.
